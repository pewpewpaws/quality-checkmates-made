# Powertrain Security Requirements Matrix

| Subsystem | Requirement Statement | ASIL Target |
| Powertrain | The inverter shall disengage torque within 20ms of over-current trigger | ASIL D |
| Gateway | The security gateway must drop unauthorized UDS diagnostic packets on the OBD bus | ASIL B |
| Battery | The BMS should balance cell voltages during AC overnight charging cycles | QM |
| Motor Controller | The motor controller shall log motor winding temperature alerts to EEPROM | ASIL C |
